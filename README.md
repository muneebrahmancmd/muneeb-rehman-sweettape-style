# 🎨 Muneeb Rehman's SweetTape-Style Portfolio

**Motion-led portfolio — Vite, GSAP, Lenis, Three.js & Matter.js. Layout inspired by sweet-tape.com.**

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Visit-brightgreen?style=for-the-badge)](https://muneeb-portfolio-50.netlify.app)
[![GitHub](https://img.shields.io/badge/GitHub-Repo-black?style=for-the-badge)](https://github.com/muneebrahmancmd/muneeb-rehman-sweettape-style)

Hi, I'm Muneeb Rehman — a creative developer, web designer, graphic designer and AI enthusiast from Pakistan. This portfolio is built around a playful tape-and-paper motion language: an animated preloader, a pull-down tape menu, an interactive work slider, and sound effects with a toggle — all wrapped in smooth scrolling and physics-driven motion.

> Layout inspired by [sweet-tape.com](https://sweet-tape.com/). All artwork and sounds in this repo are generated procedurally (see `gen/assets.py`) and all content is my own.

## ✨ Features

- Animated tape-style preloader
- Pull-down "PULL ME" tape menu with thumbnails
- Interactive work slider with rolling cards
- Procedural tape, paper and cardboard artwork
- Synthesized sound effects with a mute toggle
- Smooth scrolling with Lenis
- Physics and 3D motion with Matter.js and Three.js
- Fully responsive, from mobile to desktop

## 🛠️ Tech Stack

- **Vite 6** — dev server & build
- **GSAP 3** — animations
- **Lenis** — smooth scrolling
- **Three.js** — 3D motion
- **Matter.js** — physics
- **HTML, CSS & vanilla JavaScript**

## 🚀 Run Locally

```sh
git clone https://github.com/muneebrahmancmd/muneeb-rehman-sweettape-style.git
cd muneeb-rehman-sweettape-style
npm install
npm run dev   # http://localhost:5173
```

```sh
npm run build   # production build
npm run preview # preview the build
```
